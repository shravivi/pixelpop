# PixelPop — Pixel Art Studio

PixelPop is a colourful, beginner-friendly pixel art editor that runs in your browser. Create tiny illustrations, experiment with colour, and export your artwork as a PNG.

## Features
- Draw and erase pixels with click or drag
- Curated colour palette and custom colours
- Fill or clear the canvas
- 8×8, 16×16, 24×24 and 32×32 canvas sizes
- Toggle grid lines, undo and redo
- Demo flower to customise
- Export your creation as a PNG
- Auto-save in browser local storage
- Responsive desktop and mobile layout
- No frameworks, accounts, API keys, or installation required

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Start creating!

## Publish with GitHub Pages
1. Push the files to a GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder, then save.
5. Wait for GitHub Pages to publish the site. The URL will appear in the Pages section.

## Built with
HTML5, CSS3, vanilla JavaScript, browser Canvas API, and Local Storage.
